## Important upload instructions
1. Extract this ZIP.
2. Upload **the contents** of the extracted folder to the **root** of the GitHub repository. Do not upload only the HTML files.
3. Confirm the `assets` folder is at the same level as `index.html`, and keep all file names and capitalization exactly as supplied.
4. In GitHub, open **Settings → Pages**, choose the correct branch and `/(root)`, then save.
5. After deployment, open the Pages URL and do a hard refresh. If an older cached version remains, try a private/incognito tab.
